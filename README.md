# Xaero's Portal Locater

A client-side Fabric mod that creates linked Nether/Overworld
waypoints in Xaero's Minimap.

---

## Usage

> [!NOTE]
> Not implemented currently but `/locateportal <x y z>` works

```text
/locateportal <name> <x y z>
```

### Example:

`/locateportal basePortal` Creates a waypoint named: `P-basePortal` at the current position.

---

## Requirements
- Minecraft 1.21.1
- Fabric
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Xaero's Minimap](https://modrinth.com/mod/xaeros-minimap)
